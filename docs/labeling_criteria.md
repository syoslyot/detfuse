# 標注基準：免費食物（free_food）

此文件定義何為正例、何為負例，確保實驗的 ground truth 一致。

> **標注者：Claude（非 L1 regex）**。用 L1 自標會造成訓練資料與評估對象循環，結果無意義。

---

## 正例（label = 1）：免費食物，有送出意圖

符合下列任一條件：

1. **活動剩餘食物，開放自取** — 含「自取」「帶走」「先搶先贏」「食安自負」；不需入場或報名
2. **明確免費送出** — 「免費便當」「免費飲料」「免費餐盒」+ 地點或時間
3. **食安自負 + 食物關鍵字** — 文中有食物且沒有價格，即為正例
4. **剩食直送** — 飲料、零食、甜點等直接開放取用（非販售、非換物）
5. **宗教或公益送食** — 佛學社、法藏、社區廚房等免費提供餐點
6. **慶祝性送食** — 「發雞排」「歐趴糖」「送餅乾」等慶典或達標分享
7. **餐廳剩餘免費自取** — 當日未售出，標明免費帶走

## 負例（label = 0）：不是免費送出的食物

**負例條件優先於正例**，即使文中有食物關鍵字：

| 類型 | 說明 |
|------|------|
| Marketplace 貼文 | 含「在 Marketplace 上查看更多結果」 |
| 出售食物 | 商品售價、誠可議、降價、含明確金額 |
| 出售物品 | `^出售`、`^售`、`^賣` 開頭，主體是物品 |
| 換物條件 | 以物換食、填問卷換食物、回押金換食物 |
| 搬家或畢業出清 | 主體是物品，非送食物 |
| 工作福利 | 需工讀/就職才能享受供餐 |
| 報名才有食物 | 講座、課程、論壇等需事先報名才能吃 |
| 問卷 / 研究受試 | 填問卷換飲料券（非直接提供） |
| 出租相關 | 出租、招租、分租（連帶提到食物） |
| 共乘廣告 | 提供座位，附提食物但非送出 |
| 免費非食物 | 免費書、免費課、免費體驗（無食物） |
| 社交聚餐 | 需出席活動才能一起吃，非主動送出 |
| 餐券出售 | 出售餐廳優惠券或折扣碼 |
| 徵才招募 | 工作廣告附帶提及餐點 |
| 比賽或競賽 | 需競賽才能獲得食物獎品 |

## 邊界案例

| 情境 | 判斷 | 理由 |
|------|------|------|
| 研討會「有多」→ 剩食自取 | 1 | 明確剩餘、開放取用 |
| 研討會「有多」→ 招募志工 | 0 | 需工作才有食物 |
| 供餐活動，需報名 | 0 | 食物是報名誘因，非開放送出 |
| 供餐活動，剩食帶走 | 1 | 活動結束後開放，條件已消失 |
| 問卷送飲料券 | 0 | 條件換取，非免費 |
| 食安自負 + 便當 + 無價格 | 1 | 強正例信號 |
| 便當 + 「誠可議」 | 0 | 有售價 |
| 法藏、佛學社 + 點心 | 1 | 宗教公益，無條件送出 |
